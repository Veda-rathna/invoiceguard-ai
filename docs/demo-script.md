# Hackathon Judge & Evaluator Demonstration Script

Follow this step-by-step 3-minute walkthrough to experience the full capabilities of **InvoiceGuard AI**.

---

## 1. Launching the Platform

### Terminal 1 (Backend):
```bash
cd backend
python -m uvicorn app.main:app --reload --port 8000
```

### Terminal 2 (Frontend):
```bash
cd frontend
npm run dev
```

Open browser at: `http://localhost:5173`

---

## 2. Walkthrough Steps

### Step 1: Explore Command Center Dashboard (`/`)
- Review the **Automation Rate (83%)**, Invoices Processed, Auto-Approved, Human Review, and Blocked counters.
- Observe the **Decision Distribution Donut** and **Top Exception Drivers** bar charts.

### Step 2: Test Case 1 — Safe Invoice (`AUTO_APPROVE`)
1. In the **Instant Demo Presets** panel, click **Case 1: Safe**.
2. Watch the LangGraph multi-agent pipeline execute in real-time.
3. Observe:
   - Extracted fields with ~98% visual confidence.
   - Exact 3-way match with Purchase Order #PO-10293 (0.0% variance).
   - Risk score: 0/100 (`LOW`).
   - Decision badge: `AUTO_APPROVE`.
   - Complete agent timeline with green checkmarks.

### Step 3: Test Case 2 — PO Variance Exception (`HUMAN_REVIEW`)
1. Click **Case 2: PO Variance** in the Instant Demo panel.
2. Observe:
   - Invoice Total: ₹82,500 vs PO Total: ₹76,100.
   - Variance: **8.4%**, which exceeds the configured **5.0%** threshold.
   - Policy Agent flags `PO_VARIANCE` violation (+25 risk points).
   - Composite risk score: **72/100** (`HIGH`).
   - Decision: `HUMAN_REVIEW`.
   - Factual natural language explanation generated by Qwen3-VL explaining the exact variance.
3. Click the **Review / Override** button at the top right:
   - Enter reviewer notes (e.g., "Approved one-time server upgrade variance").
   - Click **Approve**.
   - Verify that the action creates an auditable `HUMAN_APPROVED` event on the timeline.

### Step 4: Test Case 3 — Duplicate Detection (`BLOCK`)
1. Click **Case 3: Duplicate** in the Instant Demo panel.
2. Observe:
   - Anomaly Agent detects 94% duplicate similarity with previous invoice `#INV-20391`.
   - Risk score: **94/100** (`CRITICAL`).
   - Automated routing: `BLOCK`.
   - Transaction is immediately halted to protect corporate disbursement funds.

### Step 5: Interactive Policy Simulator (`/simulator`)
1. Navigate to **Policy Simulator** in the sidebar.
2. Drag the **Allowed PO Variance** slider from 5% to 10%.
3. Drag the **Auto-Approval Limit** slider from ₹50,000 to ₹75,000.
4. Click **Run Counterfactual Simulation**.
5. Observe the live before-and-after matrix showing the projected automation rate increase and the estimated hours of manual reviewer triage saved.

### Step 6: Agent Observability (`/agents`)
1. Navigate to **Agent Observability** in the sidebar.
2. Inspect the live telemetry: Bedrock Qwen3-VL visual latency (~285ms), total tokens consumed, and execution latency across all 8 specialized agents.
